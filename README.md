# Газпром ГПА — формирование шапки ведомости

## Требования
- Python 3.12 или 3.13

## Установка
Из каталога проекта:

```bash
python -m venv .venv
```

Активируйте окружение и установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn app.main:app --reload
```

Откройте в браузере `http://127.0.0.1:8000`.

## Директории
- `data/` — исходные файлы и шаблон.
- `output/` — сформированные ведомости.

Пользователь загружать файлы через интерфейс не должен. Для обновления источников файлы заменяются администратором в каталоге `data`.
